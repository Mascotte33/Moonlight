# C2.F3.K1: Window size and UI scale in the profile

Part of [gui-calibration](../../prs/gui-calibration.md).

## Brief

`CalibrationProfile` gets `window_size` and `ui_scale` (Data shapes), read in `from_dict` and written in `to_dict`. Old profiles without them still load (PR rule P4).

**Done when:** `pytest tests/unit/test_calibrate.py` passes; a profile round-trips both fields; an old profile loads with `None` and `1.0`.

## What changed and why
