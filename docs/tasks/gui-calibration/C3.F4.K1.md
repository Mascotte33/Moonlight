# C3.F4.K1: Templates use the scale

Part of [gui-calibration](../../prs/gui-calibration.md).

## Brief

Floor, sprite and loot templates are resized by `ui_scale` once, when loaded.

**Done when:** those three test files pass, each with the same 1.5× check as C3.F2.K1. The owner tests on a real scaled server later, when one is available, and tunes `ui_scale` by hand if needed.

## Router notes

2026-10-22:
- Templates are enlarged with nearest-neighbour, which keeps pixel art crisp. If a smooth-scaled client misses, switch to linear in `scale_image`.

## What changed and why

- New `scale_image(image, scale)` in `floor.py` resizes a template by `ui_scale`. At 1.0 it returns the image unchanged.
- `FloorReader` scales an injected or lazily loaded `TemplateSet` once, through `TemplateSet.scaled`.
- `SpriteDetector` scales every monster frame once in its constructor.
- `LootReader` scales the title and item templates and the slot pitch (34 px becomes 51 at 1.5).
- Each test file gains a 1.5x check on a frame enlarged with nearest-neighbour. Without scaling, the floor check reads 4 of 16 levels right.
