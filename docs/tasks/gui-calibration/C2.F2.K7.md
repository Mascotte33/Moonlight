# C2.F2.K7: Game grid in windowed mode

Part of [gui-calibration](../../prs/gui-calibration.md).

## Brief

Owner report, 2026-10-22: with the game windowed instead of fullscreen, `find_game_grid` no longer finds the game view.

**Done when:** `find_game_grid` finds the grid on the owner's windowed screenshot, and the fullscreen golden tests still pass.

## Router notes

2026-10-22:
- Captured live from the windowed client (1234 x 815). The view is 700 x 513 at (37, 61), so size and ratio were fine.
- Cause: the lag overlay ("Low lag / fps") is drawn over the view's left line at y 71..87. The height was the unbroken dark run down that line, so it came out 11 px.

## What changed and why

- `find_game_grid` takes the height from the width (15 x 11 tiles, give or take 1 px). The left line only has to be 90% dark and end at the bottom corner, so text over it no longer breaks the finder.
- Test: a drawn windowed view with the overlay over its left line and the light bevel on the bottom and right edges. The fullscreen golden tests still pass.
