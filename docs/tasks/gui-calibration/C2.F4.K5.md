# C2.F4.K5: Named calibrations

Part of [gui-calibration](../../prs/gui-calibration.md).

## Brief

Today the tab always overwrites the profile named in the bot config (`moonlight_user`), and nothing in the GUI shows or changes which one the bot uses.
  - The Calibration tab shows a dropdown of saved calibrations (one per file in the profiles folder). Picking one sets the config's `profile` field, so the bot uses it on its next start.
  - The review has Save (writes the picked calibration) and Save as (asks for a name, then saves under it and picks it). An existing name asks before overwriting.
  - Esc's partial save writes the picked calibration.

**Done when:** pytest passes, with tests for name checks and listing (tmp_path only). Owner checks: save as a new name, switch between two calibrations, start the bot and see it use the picked one.
