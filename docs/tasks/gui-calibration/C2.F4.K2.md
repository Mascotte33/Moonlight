# C2.F4.K2: Calibration tab

Part of [gui-calibration](../../prs/gui-calibration.md).

## Brief

A **Calibration** entry in the GUI sidebar, built on C2.F4.K1.
  - **Start calibration** waits 3 seconds (so the user can switch to Tibia), then takes a screenshot of the game area. No Tibia window: an error in the log, nothing opens. Greyed out while the bot runs.
  - **Load screenshot** picks a PNG instead; the picture's size is the window size.
  - Each area is shown zoomed to full size with a margin around its box. An area with no box starts on the whole screenshot and zooms in after the first rough drag.
  - Enter keeps, drag redraws, Backspace goes back.
  - The review shows the 7 boxes and an editable **UI scale** number. Clicking a box fixes that area. **Save** writes the profile.
  - Esc asks "Save what you have?". Yes = partial save (C2.F4.K1), No = nothing changes.
  - With no reference images, the tab says "No reference images, draw the boxes by hand".

**Done when:** `pytest tests/unit/test_gui_calibration.py` passes (screen box ↔ screenshot box maths for the zoomed view). Owner checks: calibrate on the live client and from a golden screenshot, fix one box from the review, Esc and save what you have.

## Router notes

2026-10-22:
- `CalibrationSteps` (C2.F4.K1, `moonlight/setup/calibration_steps.py`):
  - `CalibrationSteps(screenshot_size, found, old_profile=None, landmark=(0, 0))`. `screenshot_size` is `(w, h)`.
  - Read `in_review`, `area` (None in the review), `box` (None when the area has no box), `can_save`, `boxes`, `confirmed`. Set `ui_scale`.
  - Call `keep()`, `redraw(rect)`, `back()`, `pick(name)` (review only), `save()` (raises unless `can_save`) and `save_partial()`.
  - Both saves return a `CalibrationProfile`. The tab writes it with `.save(path)`.
- `found` comes from `autofind.find_regions(screenshot)[0]`. The screenshot is BGR, as `ScreenCapture.get_frame()` and `cv2.imread` give it.
- The old profile and the save path:
  - Load the old profile from the active profile the bot uses (see how `gui/loop_factory.py` picks `profile` and `profiles_dir`).
  - Save back to the same file.
  - Tests never write into `moonlight/profiles/`. Use `tmp_path`.
- Start calibration:
  - Wait with `root.after(3000, ...)`, never `sleep`.
  - Then call `ScreenCapture().get_frame()` once and close it.
  - `WindowNotFoundError` or `CaptureError` logs an error through `ctx.log` and nothing opens.
  - The button is disabled while `ctx.bot_running()`. Refresh it in `on_poll`.
- Load screenshot uses `tkinter.filedialog`, PNG only, and `cv2.imread`.
- No Pillow import (R6, pyproject does not list it). To show a crop:
  - Crop and scale with cv2.
  - Encode with `cv2.imencode(".png")`.
  - Show it with `tk.PhotoImage(data=base64)` on a plain `tk.Canvas`.
- The zoom maths goes in pure functions in `calibration.py`, tested without a window (R8):
  - `view_rect(box, screenshot_size, margin)` clamps to the screenshot. `None` gives the whole screenshot.
  - Screen to screenshot coordinates and back for a view shown at a scale.
  - The drag rect is normalized and clamped.
  - Margin is about half the box size, with a floor in px. Your call.
- A missing area shows the whole screenshot. The first drag there is the rough one: zoom to it and stay on the same area. The second drag is `redraw`.
- Keys are bound on the canvas, and the canvas takes focus when the steps open. The keys are Enter, Backspace and Esc. A drag is press, motion, release with a visible rectangle.
- The review:
  - The whole screenshot is scaled to fit, with the 7 labelled boxes.
  - Clicking inside a box calls `pick`.
  - It has a UI scale entry (float, 0.5 to 3.0) and Save. Save is disabled unless `can_save`.
  - Save logs `profile saved to <path>`.
- Esc opens a yes/no dialog, "Save what you have?". Yes calls `save_partial()` and saves. No closes the steps without saving. Both return to the tab's idle view.

## What changed and why

- New `moonlight/gui/tabs/calibration.py`: the Calibration tab, added to `TAB_ORDER` after Settings in `gui/app.py`.
- Start calibration waits 3 s with `after`, grabs one frame and closes the capture. A capture error goes to the log and nothing opens. The button is greyed out while the bot runs or the 3 s wait is on.
- `ScreenCapture.get_frame()` returns RGB, not BGR as the notes said, so the tab flips it to BGR before `find_regions`.
- The zoom maths is pure functions (`view_rect`, `fit_scale`, `to_screenshot`, `to_canvas`, `drag_rect`, `box_at`), tested in `tests/unit/test_gui_calibration.py`. Margin is half the box's bigger side, at least 40 px.
- A drag shorter than 3 screen px is a click. In the review a click picks the smallest box under it.
- The UI scale entry starts at the old profile's `ui_scale`. Esc's partial save keeps that value.
- The profile path is `ProfileManager(cfg.profiles_dir).path(cfg.profile)` from the picked config. An unreadable old profile counts as none.
- The reference images note checks `<templates_dir>/anchors` for any PNG.
